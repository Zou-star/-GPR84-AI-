# GPR84-ML-v3-official-1

面向缺血性脑卒中炎症相关靶点 GPR84 的小分子 AI 虚拟筛选与候选优选平台。

本仓库提供项目核心的可复现机器学习建模、分子特征计算、批量预测与候选筛选流程，用于支持 GPR84 靶向小分子的早期发现与后续验证。

---

## 1. 项目简介

本项目聚焦缺血性脑卒中炎症调控相关靶点 GPR84，构建“公开实测药理数据重建—分子结构标准化—机器学习建模—十万级商业化合物筛选—多证据复筛—候选物实验验证”的 AI 虚拟筛选流程。

项目基于公开来源的 GPR84 实测药理数据，经结构标准化、标签审计和质量控制后，形成 400 个冻结建模结构，并系统比较 6 套分子表征与 7 类机器学习算法。

最终选定 XGBoost_F4 作为正式评分模型，并冻结为：

`GPR84-ML-v3-official-1`

---

## 2. 正式模型信息

- 正式模型：XGBoost_F4
- 模型版本：GPR84-ML-v3-official-1
- 冻结训练结构：400 个
- 阳性结构：326 个
- 阴性结构：74 个
- 分子表征：MACCS 167 位结构指纹
- 分子描述符：10 项
- 总输入维度：177 维
- 随机种子：42

正式模型输入由：

`MACCS 167 位指纹 + 10 项分子描述符`

组成，共 177 维特征。

---

## 3. 模型开发与评价

项目系统比较：

- 6 套分子表征
- 7 类机器学习算法
- 共 42 种基础模型组合

主要比较算法包括：

- Logistic Regression
- RBF-SVM
- Random Forest
- ExtraTrees
- XGBoost
- LightGBM
- CatBoost

为降低同论文来源及相近化学系列跨训练集和验证集造成的信息泄漏风险，项目采用论文关联分组的折外预测作为主要评价方式，并进一步开展：

- 滚动时间窗口评价
- 骨架压力测试
- Bootstrap 重采样
- 多随机种子稳定性分析

主要开发评价结果：

| 指标 | 结果 |
|---|---:|
| 论文关联分组 OOF ROC-AUC | 0.9376 |
| MCC | 0.7544 |
| Balanced Accuracy | 0.8213 |
| 四个时间窗口平均 AUC | 0.7396 |

注意：

`ROC-AUC = 0.9376` 属于模型开发阶段的论文关联分组 OOF 评价结果，不代表独立外部验证结果。
